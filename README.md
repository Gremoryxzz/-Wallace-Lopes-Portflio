## 🚀 Tecnologias utilizadas

* HTML5
* CSS3 (variáveis CSS, grid, flexbox)
* JavaScript puro, sem frameworks nem bibliotecas

---

## 🎯 Funcionalidades

* Layout moderno e responsivo, para celular e computador
* Tema claro e escuro, que acompanha a preferência do sistema
* Site em português e inglês, com botão para trocar o idioma
* Fundo de estrelas animado em canvas
* Linha do tempo de experiência que acende conforme a rolagem
* Cards de projetos com efeito de inclinação ao passar o mouse
* Seção **Contate-me** com links diretos para WhatsApp, LinkedIn e GitHub

## 🧩 Projetos em destaque

* **Libris:** sistema de recomendação de livros em Python, com Google Books, Open Library, Machine Learning e NLP
* **FolhaPonto:** folha de ponto com histórico e cálculo de horas trabalhadas
* **App para igreja:** aplicativo com login, perfil, troca de senha e chat
